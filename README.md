## 项目简介

平时电脑开着也是开着，就让它跑着玩，万一中彩票呢。

**BTC 工具箱**（v2.0）是一款桌面端多链区块链工具集，支持 Bitcoin、Ethereum、TRON 等主流网络。软件提供助记词碰撞、私钥碰撞、助记词找回、靓号生成等核心能力，遵循 BIP39 / BIP32 / BIP44 标准，全部在本地离线完成计算与存储。

### 核心特性

| 维度 | 说明 |
| ---- | ---- |
| **专业** | 标准加密算法与 BIP 协议，结果可验证 |
| **高效** | 多线程并发 + 布隆过滤器分桶匹配 |
| **安全** | 完全离线运行，私钥仅保存在本地 |
| **易用** | 首页总览 + 各模块内置使用说明 |

## 核心功能

### 1. 助记词碰撞

随机或按顺序生成 12 位助记词，派生多链地址并与本地地址库比对。

- 支持 BTC（1 / 3 / bc1q）、ERC20、TRC20
- 随机模式与顺序遍历模式（支持断点续跑）
- 标准或自定义 BIP44 派生路径
- 命中后自动停止并写入 `work/success/mnemonic/`

### 2. 私钥碰撞

在指定私钥区间内遍历，或在大范围内随机采样，派生地址进行比对。

- 支持设置私钥起止区间或位数范围
- 随机 / 顺序两种遍历方式，顺序模式支持续跑
- 多链、多地址类型同时派生
- 命中后自动保存（BTC 为 WIF，EVM / TRON 为 HEX）

### 3. 助记词找回

根据部分已知助记词、候选词或目标地址，在规则空间内搜索完整 12 词组合。

- 12 个词位可独立配置规则（见下表）
- 可填写目标地址进行定向找回
- 也可加载地址库进行批量比对
- 完整功能需激活授权；体验版有线程与时长限制

**助记词规则说明：**

| 规则类型 | 说明 | 示例 |
| -------- | ---- | ---- |
| **精确** | 该位置助记词完全正确 | 第 1 位已知为 `shop` |
| **候选词** | 从多个候选词中枚举 | 第 3 位可能是 `apple` 或 `angle` |
| **遗忘** | 该位置完全未知，从 BIP39 词库全量枚举 | 完全不记得第 5 位 |
| **前缀字母** | 记得开头字母 | `shop` 可填 `s` 或 `sh` |
| **后缀字母** | 记得结尾字母 | `shop` 可填 `p` 或 `op` |
| **包含字母** | 记得包含某字母 | `shop` 可填 `o` 或 `h` |

### 4. 靓号生成

按自定义规则生成专属靓号地址，无需地址库。

- 快捷规则：豹子号、顺子号、对称号、寓意号
- 自定义前缀 / 后缀 / 包含匹配
- 生成来源：随机助记词或随机私钥
- 多条规则命中任一即视为成功，结果写入 `work/success/vanity/`

| **TRON** | `T` | TRC20 标准地址 |

## 使用流程

### 第一步：下载与安装

1. 从上方下载链接或 Telegram 频道获取安装包
2. 解压后运行主程序（如 `BTC工具箱.exe` 或 `wallet_tool.exe`）
3. 首次启动会自动创建 `work/` 工作目录

> **系统要求**：Windows 7 / 8 / 10 / 11 64 位

### 第二步：准备工作区

程序运行目录（或开发时仓库根目录）下的 `work/` 结构如下：

```
work/
├── address/          # 地址库 txt（每行一个地址，按前缀自动识别链路）
├── success/          # 命中结果
│   ├── mnemonic/     # 助记词碰撞
│   ├── private/      # 私钥碰撞
│   ├── recovery/     # 助记词找回
│   └── vanity/       # 靓号生成
├── config/           # 应用配置（预留）
└── data/
    └── db.properties   # 本地授权配置
```

**地址库说明：**

- 将 txt 地址文件放入 `work/address/`（平铺存放，无需子目录）
- 程序按地址前缀自动归类：BTC `1`/`3`/`bc1q`、ETH `0x`、TRON `T`
- 在碰撞类模块页面点击加载地址库，首次会建立索引，之后复用缓存

### 第三步：选择功能模块

在主界面 Tab 或首页卡片进入对应模块，配置参数后点击顶部 **开始**。

#### 助记词碰撞

1. 确认 `work/address/` 中已有地址文件并已加载索引
2. 选择链路（BTC / ERC20 / TRC20）及地址类型
3. 选择随机或顺序生成，配置派生路径
4. 调整 CPU 线程数后点击开始

#### 私钥碰撞

1. 加载地址库
2. 选择链路与地址类型
3. 设置私钥区间或位数，选择随机 / 顺序模式
4. 点击开始

#### 助记词找回

1. 为 12 个词位配置规则（越准确、顺序越明确，搜索越快）
2. 可选填目标地址，或依赖地址库比对
3. 配置链路与高级参数后点击开始

#### 靓号生成

1. 选择链路与地址类型
2. 添加豹子 / 顺子 / 寓意等规则，或自定义前缀 / 后缀 / 包含
3. 选择助记词或私钥作为生成来源
4. 点击开始，命中即停

### 第四步：查看结果

- 命中后任务自动停止，界面弹出命中详情
- 结果文件保存在 `work/success/{模块名}/` 对应目录
- 可通过弹窗或系统按钮直接打开输出目录

## 技术特性

### 安全性

- 完全离线运行，无需联网
- 私钥与助记词仅本地存储，不上传服务器
- 遵循 BIP39 / BIP32 / BIP44 标准
- 核心算法基于 Rust 生态成熟库实现

### 高性能

- 多线程并发，可按 CPU 核心数调节
- 地址库按链路分桶布隆过滤，降低误判与内存压力
- SQLite 辅助索引，大库加载后可快速复用
- 实时速度、进度与日志输出

### 智能化

- 助记词找回多规则组合枚举
- 顺序模式断点续跑，避免重复计算
- 命中自动停止并归档结果
- 各模块内置「使用说明」入口

## 常见问题

### Q: 支持哪些操作系统？

A: 目前主要支持 Windows 7 / 8 / 10 / 11 64 位。

### Q: 是否需要联网？

A: 不需要。计算与存储均在本地完成；仅联系客服或下载更新时需要网络。

### Q: 地址库放在哪里？

A: 放在程序目录下的 `work/address/`，txt 格式，每行一个地址。v2.0 不再使用旧版的 `input` 目录。

### Q: 如何提高助记词找回速度？

A: 尽量使用「精确」「候选词」规则，减少「遗忘」词位；已知目标地址时可填写定向找回。

### Q: 顺序模式中断后如何继续？

A: 再次启动同模块、同配置点击开始，程序会提示是否从断点续跑；断点文件位于 `work/cache/checkpoints/`。

### Q: 索引缓存可以删除吗？

A: 可以。删除 `work/cache/address_index/` 后下次加载地址库会重新建索引；不影响地址源文件。
